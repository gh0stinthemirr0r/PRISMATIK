# @prismatik/api-client

This package is the destination for TypeScript bindings generated by
`tauri-specta`. The generated output is the contract between the Tauri shell and
the PRISMATIK Svelte frontend.

Do not hand-edit files in `src/generated/` once Specta export is live. Update the
Rust command contracts, run the binding generator, and commit the resulting
output together with the contract change. `src/index.ts` is the stable public
entry point and only re-exports generated code.

**Current status (ADR-0031):** Specta `2.0.0-rc.25` does not build on MSRV 1.88,
so `prismatik-desktop` ships with a scaffold `bindings.ts` and the drift-check
scripts. Re-enable automatic export when Specta builds on the pinned toolchain.

Run `scripts/check-bindings-drift.sh` on Unix-like systems or
`scripts/check-bindings-drift.ps1` on Windows after generation. Both scripts
fail when the generated directory differs from the committed tree.
